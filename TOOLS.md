# Tools

Skills in this repo speak in verbs: check the CRM, pull the call, schedule the post. This page lists the tools recommended for each verb. They are recommendations from running these playbooks at B2B companies, not requirements. A spreadsheet and a mail client cover most of the early work. Once a company has a marketing brain, its own `1-context/stack.md` names the tool it actually uses and wins over this page.

| Verb in a skill | Recommended | Also works | Notes |

## Rules that hold whatever the tool

- One tool per job. Two sequencing tools or two booking tools is a leak.
- Every lead reaches the CRM with a source.
- Read access first; write access only with an approval step.
- Nothing goes to a customer, a prospect or the public without a person reading it.
- Deal values and customer commercials never enter the marketing brain.
