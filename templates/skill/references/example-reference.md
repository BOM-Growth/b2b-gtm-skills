# Example reference page

A reference page holds the depth a skill routes to: a scoring rubric, a template, worked examples, a channel variant. It is read only when the skill says to read it.

## Shape

- Title says what the page is for.
- One line on when to read it.
- The rubric, template or examples, with no prose around them that the SKILL.md already carries.
- Every threshold is either a value from `context/` or marked as a default the company should override.

## Example: a scoring rubric

| Test | Pass | Fail |
|---|---|---|
| [criterion] | [what pass looks like] | [what fail looks like] |

Fails [n] of [m] means [decision].
