# Stack
Status: draft

Skills speak in GTM verbs. This file maps each verb to the company's tool and names the system of record for each kind of fact. Swap a tool, change one line here.

| Verb in a skill | Tool | System of record for |
|---|---|---|
| check the CRM, update the deal, pull the pipeline | [CRM] | Contacts, companies, deals, stages, first-touch source |
| run a sequence, enroll a cohort | [sales engagement tool] | Outbound enrollment and replies |
| pull the call, read the transcript | [call recorder for external calls] | Customer and prospect call recordings |
| read the internal meeting | [notes tool for internal meetings] | Internal meeting notes |
| pull paid search data | [ad platform and reporting tool] | Search campaigns and spend |
| pull paid social data | [ad platform and reporting tool] | Social campaigns, engaged accounts |
| pull site traffic | [web analytics] | Visits |
| identify site visitors | [visitor identification tool] | Alerts only |
| book a demo, check the routing form | [scheduling tool] | Bookings and routing rules |
| schedule a post | [social scheduler] | Published posts |
| deploy a page | [site framework and host] | Site pages |
| check the proof tracker | [permissions tracker] | Customer permissions, quotes, logos |
| check the events system of record | [events hub] | Event owner, team, booth, travel, tasks |
| read the release record | [product release sheet or roadmap] | What shipped, what is not released yet |
| read the brand tokens | [design system] | Colors, type, logo rules |
