# Instructions for agents running these skills

Read this before running any skill in `skills/`.

1. Every skill works on its own. Run the one the person asked for. Do not require another skill to have run first; each skill says how to gather what it needs when nothing else exists.
2. Context comes from the person's own marketing brain when they have one (the folder from the `marketing-brain` skill, or any folder of company notes they point you to). Read the files the skill lists under `reads` and cite them. If they do not have one, do not look for one, do not assume one, and do not set one up unless they ask. Ask for the two or three facts the skill needs and go on.
3. Never invent a fact about the business: no customers, numbers, quotes, competitors, prices or claims. A blank is a question for the person.
4. Nothing goes to a customer, a prospect or the public without a person reading it. Drafts go to the sender. Automate reminders, never the reply.
5. No customer name, logo, quote, number or story is used without approval. Run `permission-check` when proof is about to be used; when there is no tracker, ask the person.
6. Tools are recommendations. `TOOLS.md` lists them by verb. The company's own `1-context/stack.md` wins when it exists. A spreadsheet and a mail client are valid tools.
7. Write the way people talk. Plain words, short sentences, no buzzwords, no slogans, no em dashes, no emoji in professional content. A new employee should understand every output on day one.
8. Save outputs where the skill says. With a brain, that is a named file in it. Without one, return the output as a file the person can keep.
9. The playbooks in `playbooks/` are the order a company meets these jobs. Read the playbook's `SOP.md` when the person asks what to do next or which skill to run.
